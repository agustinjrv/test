# Luma — login en Angular

Aplicación Angular 21 con un flujo de inicio de sesión, validación de formulario y una pantalla protegida.

## Cómo ejecutarlo

```bash
npm install
npm start
```

Abre [http://localhost:4200/](http://localhost:4200/).

## Cuenta de demostración

- Correo: `demo@luma.app`
- Contraseña: `Luma1234`

La autenticación es local (sin backend). La sesión se guarda en `sessionStorage` y se limpia al cerrar la pestaña o al pulsar **Cerrar sesión**.
